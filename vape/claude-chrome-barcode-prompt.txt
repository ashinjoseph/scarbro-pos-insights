HOW TO FIND THE BARCODES

The official brand stores and most Canadian vape retailers run on Shopify. Every Shopify store publishes a plain JSON list of all its products, including a "barcode" field on each variant, at:

    https://<store>/products.json?limit=250

Open that URL directly in the browser and read the JSON. Each product has "title" and "variants"; each variant has "title" (usually the flavour), "sku", "barcode" and "price". If a store returns exactly 250 products, there is another page: add &page=2 (and &page=3, etc.) until a page returns fewer than 250.

Use these sources, in this order of preference:

1. https://stlthvape.com/products.json?limit=250          (STLTH — all lines)
2. https://flavourbeast.com/products.json?limit=250        (Flavour Beast and Level X)
3. https://shopelfbar.ca/products.json?limit=250           (Elf Bar FS70K, GH20K)
4. https://www.allovapor.com/products.json?limit=250       (Allo)
5. https://bayvape.ca/products.json?limit=250              (retailer — use for OVNS, Krave, Drip'n, and any gaps)
6. https://hazetownvapes.com/products.json?limit=250       (second retailer — gaps only)
7. https://www.canvape.com/products.json?limit=250         (third retailer — gaps only)

Only fall back to ordinary product pages or search if the JSON route fails for a store. Do not use UPC-lookup websites; they are unreliable for these products.

MATCHING RULES

- Match on product line AND flavour. "Blue Razz" and "Blue Razz Ice" are different products. "Watermelon Ice" under ECO and "Watermelon Ice" under FS70K are different products.
- These are Ontario-stamped products. If a store lists the same flavour with province variants (labelled ON, Ontario, [ON], AB, BC, MB, Federal, etc.), take the Ontario one. If only one variant exists with no province label, take it and note "no province label".
- Prefer the official brand store's barcode over a retailer's. If two sources disagree, record both, official first, and note it.
- A retail barcode should be 12 digits (UPC-A) or 13 digits (EAN-13). STLTH codes start 691584. Allo, Flavour Beast and Level X codes start 827152. If a code you find does not fit these patterns, still record it but flag it in Notes.
- If a store's barcode field is empty or missing for a product, say so — do not substitute the SKU, the product ID, or a code from a different flavour.
- Do not guess or invent a barcode under any circumstances. An empty cell is the correct answer when nothing is found.
- Some sources list a separate carton/case barcode. If you see one, put it in the Carton Barcode column; otherwise leave that column empty.
